Method Launcher

Every app, one download.

The front door to the Method Production Suite. See every app, install the ones you want, keep them up to date and open them, from one small window.

Download for Mac Windows and Linux

What it does

  • Install with one click. Each app comes from its own latest release.
  • Updates in one place. See which apps have a new version, then update one or all of them. It asks before it quits an app you have open.
  • Your recent files, across the suite. Scripts, schedules and budgets you opened lately, each opening in the app it belongs to.
  • Demo the suite. Opens your installed apps on Field Station, an invented production, so you can see how they fit together before you use your own work. (Method Reader joins in from its next release.)

How it checks a download

Nothing runs until it passes. Every app must be signed by the suite's Developer ID and notarised, and must match the checksum its release publishes. If a check fails, nothing is installed.

Platforms

macOS on Apple silicon, Windows (x64) and Linux (x86_64). Installing and updating apps from inside the launcher works on the Mac today; on Windows and Linux it shows every app and its version and links each one's download page, and installing there comes next. The Windows installer is not signed yet, so Windows may warn you before it opens.

Private by default

No account, no server of its own and no tracking. It talks only to GitHub, to check for and download releases, and you can turn update checks off. It never changes your files.

Free and open source

MIT or Apache-2.0, like every Method app. The code is on GitHub.
