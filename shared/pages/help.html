Help build it

Help put professional film tools in everyone's hands.

There are two ways in. Most of what these apps need is film knowledge, not code. Talk to us and everyone else working on Method in GitHub Discussions.

If you make films

Check the apps against what you know and tell us where they're wrong. Open an issue in the app's repository with what you checked and what you found.

Never attach real production material: no real budgets, schedules or unreleased scripts. An invented file always shows the problem.

If you write code

Pick an issue labelled good first issue, run the repository's checks (the README gives the one command) and send a pull request. AI-assisted changes are welcome on an accepted issue, from an author who can explain every line.

Bring it to more people

The signed apps are Mac only today, in English, with mostly US rate data. Windows and Linux testing, translations, rate cards and currencies from other countries, older hardware and screen-reader checks all widen who can use them, and each one is a good first contribution.

Hear when it ships

Write to {hello} and we'll tell you when Method Schedule ships. On GitHub, Watch → Custom → Releases on any app's repository does the same.

Every release names the people who helped, film knowledge included.
